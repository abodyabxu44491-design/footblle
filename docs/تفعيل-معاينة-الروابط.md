# تفعيل معاينة روابط البطولات (اسم البطولة وشعارها في واتساب)

الشيفرة جاهزة في `functions/index.js`. **لم تُوصَل** بإعدادات النشر عمداً، لأنها تحتاج خطة **Blaze** (الدفع حسب الاستخدام) في Firebase. ولو وُصلت بلا تفعيل لفشل نشر الموقع.

التكلفة عملياً صفر: الدالّة تُستدعى فقط عند فتح رابط `/l/...`، والطبقة المجانية تغطي مليوني استدعاء شهرياً.

## الخطوات

1. فعّل خطة Blaze من Firebase Console ← Usage and billing.
2. أضف إلى `firebase.json`:
   - في القسم الرئيسي:
     ```json
     "functions": { "source": "functions" },
     ```
   - داخل `"hosting"`:
     ```json
     "rewrites": [ { "source": "/l/**", "function": "leaguePreview" } ],
     ```
3. انشر:
   ```bash
   cd functions && npm install && cd ..
   firebase deploy --only functions,hosting
   ```
4. جرّب: افتح `https://footblle2.web.app/l/<معرّف-البطولة>`، ثم الصق الرابط في واتساب.

## بعد التفعيل
شارك الروابط بصيغة `/l/<المعرّف>` بدل `league-viewer.html?id=<المعرّف>`. الروابط القديمة تبقى تعمل.

> ملاحظة: شعار البطولة يظهر في المعاينة فقط إن كان رابط `https://`. الشعار المخزَّن كصورة مضمّنة (`data:`) لا تقرؤه الزاحفات، فتظهر صورة المنصة بدلاً منه.
