✨ نسخة محدّثة: تصميم رياضي + كل الأيقونات SVG بدل الإيموجي

🖼️ معاينة كل بطاقات المشاركة الأربع

نفس كود الرسم بالضبط من viewer.js الفعلي، ببيانات تجريبية.

1️⃣ مشاركة التشكيلة
ملعب بشرائط عشب متبادلة + أقواس جزاء ومنتصف حقيقية + أقواس أركان + مقاعد بدلاء بأيقونة SVG.
2️⃣ مشاركة آخر 5 هدّافين
أيقونة كأس SVG بالرأس + ميداليات دائرية للثلاثة الأوائل + أيقونة كرة SVG بجانب كل رقم أهداف.
3️⃣ مشاركة إحصائيات اللاعب
لقب بأيقونة SVG (هدف/نجمة/درع...) + شبكة إحصائيات بأيقونات SVG + بطاقات وسجل مباريات بأيقونات كرة/قفاز.
4️⃣ مشاركة ترتيب المجموعة
أيقونة مجموعة SVG بالرأس + شارات تأهل/خروج بعلامة صح/إكس SVG موحّدة.
